This section is the system locus for services which model, run, or observe
simulated dynamical systems through composed runtimes, engines, solvers, and
observers. Descending service sections add capability predicates; they do
not grant an ancestor authority to perform the terminal Actor's operation.

## Holdings

- `services/biology-simulation-services-section` — simulated biological
  systems: cells, organisms, and their populations. First holding: the
  `natural-computer-simulation-engine` keystone app, a membrane-bounded single-cell
  simulator built on the estate's own predication/settling substrate
  rather than on numeric mechanism or learned representation alone.
- `services/astronomy-position-computation-service` — deterministic celestial
  position and event computation, with an optional bounded DE440 provider.
